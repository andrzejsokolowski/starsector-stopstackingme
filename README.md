# StopStackingMe

A simple Starsector utility mod that removes the extra sprites rendering as ghosts behind weapons in
cargo screens.

Covers every screen that shows cargo tiles — the cargo screen, trading, storage, loot, and the weapon
picker in refit. The quantity number in the corner, tooltips and drag-and-drop are left alone.

[Forum thread](https://fractalsoftworks.com/forum/index.php?topic=35952.0)

## Settings

Through LunaLib's settings menu (`Shift+F2` in the campaign), under **Icons**:

- **Weapons - one sprite only** — on by default.
- **Crew and marines - one sprite only** — off by default. Crew and marine stacks pile up the same
  way, one extra portrait per 50 aboard.

## Requirements

- [LunaLib](https://fractalsoftworks.com/forum/index.php?topic=25658.0)
- [LazyLib](https://fractalsoftworks.com/forum/index.php?topic=5444.0)
